# Hypotheses log

Rules (from the assignment): before each block of experiments, write the hypothesis and the
predicted outcome and **commit it before running the block** (the git history is checked).
After the block, add what happened and why, without editing the "before" part.

Template for one block:

```
## <block id>: <short name>          (committed before: <date>)
**Hypothesis.** ...
**Prediction.** <metric, expected value or direction, e.g. "CV EMD 25 ± 5, better than X by > 3">
**Experiments.** <config names / table rows>
---
**Result** (added <date>). <numbers from results table>
**Why.** ... (a wrong prediction with a good explanation is graded like a correct one)
```
